# 수능영어 문항번호별 생성 도메인 개선 계획

## 개요
이 문서는 `csat_english` 도메인을 정교하게 개선하기 위한 계획을 담고 있습니다.

---

## 1. 문항별 상세 프롬프트 템플릿

### 현재 상태
| 필요 요소 | 현재 상태 | 개선 필요 |
|-----------|----------|----------|
| prompt_template | 일부만 있음 | 전체 45개 필요 |
| output_format | 일부만 있음 | JSON 스키마 표준화 |
| 예시 문항 | 없음 | 기출 기반 예시 추가 |

### 작업 내용
- [ ] 듣기 문항 (1-17번) 전체 템플릿 작성
- [ ] 독해 문항 (18-45번) 전체 템플릿 작성
- [ ] 각 문항별 JSON 출력 스키마 표준화
- [ ] 기출 예시 문항 최소 1개씩 추가

## 2. 기출 분석 데이터 통합

### 필요한 데이터
```
- 최근 5개년 수능/모의평가 기출 문항
- 문항별 정답률 (난이도 지표)
- 오답 선택지별 선택률 (매력적 오답 분석)
- 지문 주제/소재 분포
- 어휘 수준 분석
```

### 작업 내용
- [ ] 2020-2024 수능 기출 문항 수집
- [ ] 문항별 정답률 데이터 정리
- [ ] 오답 선택률 분석 데이터 추가
- [ ] 주제/소재 빈도 분석

## 4. 오답 설계 가이드라인

### 오답 설계 전략
```python
DISTRACTOR_STRATEGIES = {
    "부분 일치": {
        "설명": "지문 일부만 맞고 전체적으로 틀림",
        "예시": "지문에서 언급된 세부 사항을 전체 주제로 오해하게 유도"
    },
    "과잉 일반화": {
        "설명": "지문보다 범위가 넓음",
        "예시": "'Some students...'를 'All students...'로 확대"
    },
    "과잉 구체화": {
        "설명": "지문보다 범위가 좁음",
        "예시": "일반적 진술을 특정 상황에만 적용"
    },
    "반대 진술": {
        "설명": "지문과 반대되는 내용",
        "예시": "긍정을 부정으로, increase를 decrease로"
    },
    "언급 없음": {
        "설명": "지문에 없는 그럴듯한 내용",
        "예시": "주제와 관련 있지만 지문에 없는 정보"
    },
    "혼동 유발": {
        "설명": "유사 개념이나 표현 사용",
        "예시": "effect vs affect, principle vs principal"
    },
}
```

### 문항 유형별 오답 전략
| 문항 유형 | 권장 오답 전략 |
|----------|---------------|
| 주제/요지 | 부분 일치, 과잉 일반화 |
| 빈칸 추론 | 부분 일치, 반대 진술 |
| 어휘 | 혼동 유발, 반대 진술 |
| 내용 일치 | 언급 없음, 반대 진술 |

### 작업 내용
- [ ] 오답 설계 전략 상세 가이드 작성
- [ ] 문항별 권장 오답 전략 매핑
- [ ] 오답 예시 추가

## 5. 어휘 수준 데이터베이스

### 필요한 어휘 데이터
```
- 수능 필수 어휘 3,500개 (등급별 분류)
  - 기초 어휘 (1,000개): 중학 수준
  - 필수 어휘 (1,500개): 고등 기본
  - 고급 어휘 (1,000개): 수능 고난도
- EBS 연계 어휘 목록
- 빈출 어휘 순위 (최근 5개년)
- 문항별 적정 어휘 수준
- 다의어/혼동 어휘 목록
```

### 어휘 수준 기준
| 수준 | 단어 수 | 설명 |
|-----|--------|------|
| 기초 | ~1,000 | 중학 필수 |
| 중급 | ~2,000 | 고1-2 수준 |
| 고급 | ~3,000 | 수능 필수 |
| 심화 | ~3,500 | 고난도 문항 |

### 작업 내용
- [ ] 수능 필수 어휘 목록 구축
- [ ] 어휘 등급 분류
- [ ] 문항별 어휘 수준 가이드라인 작성

## 7. EBS 연계 스타일 가이드

### 연계 유형
| 연계 유형 | 설명 | 예시 |
|----------|------|------|
| 직접 연계 | 지문/소재 동일, 문항 유형 변경 | EBS 독해 지문 → 수능 빈칸 추론 |
| 간접 연계 | 주제/소재 유사, 지문 신규 작성 | EBS 환경 주제 → 수능 유사 환경 지문 |
| 어휘 연계 | EBS 핵심 어휘 활용 | EBS에서 다룬 다의어/숙어 활용 |

### EBS 연계 작성 원칙
1. EBS 교재의 주제/소재 분석
2. 핵심 개념 추출
3. 새로운 맥락에서 재구성
4. 수능 유형에 맞게 문항 설계

### 작업 내용
- [ ] EBS 연계 유형별 템플릿 작성
- [ ] 연계 작성 가이드라인 상세화
- [ ] 예시 문항 추가

## 구현 우선순위

| 우선순위 | 항목 | 효과 | 예상 작업량 |
|---------|------|------|-----------|
| **1순위** | 전체 문항 프롬프트 템플릿 완성 | 기본 품질 확보 | 높음 |
| **2순위** | 기출 예시 문항 추가 | 실제 수능 스타일 학습 | 중간 |
| **3순위** | 오답 설계 가이드라인 | 문항 변별력 향상 | 중간 |
| **4순위** | 어휘/문법 데이터베이스 | 수준 적합성 | 높음 |
| **5순위** | 품질 검증 자동화 | 일관된 품질 유지 | 높음 |
| **6순위** | EBS 연계 가이드 | 실제 수능 연계율 반영 | 중간 |
| **7순위** | 인지 수준 매핑 | 체계적 문항 설계 | 낮음 |
