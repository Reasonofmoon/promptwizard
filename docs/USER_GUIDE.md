## 앱 소개

### 개요
**Domain-Aware Prompt Optimizer**는 도메인 전문가의 암묵지(Tacit Knowledge)를 프롬프트에 반영하여 AI 응답 품질을 향상시키는 도구입니다.

### 핵심 가치
```
일반 프롬프트 → 도메인 암묵지 주입 → 전문가 수준 프롬프트
```

### 지원 도메인
| 도메인 | 설명 | 주요 용도 |
|--------|------|----------|
| 🏥 의료 | 헬스케어, 의학 정보 | 의료 상담, 건강 정보 |
| ⚖️ 법률 | 법률 정보, 가이드 | 법률 자문, 계약 검토 |
| 💰 금융 | 금융/투자 정보 | 투자 조언, 재무 분석 |
| 📝 영어문항생성 | 영어 시험 문항 | 학교 시험, 모의고사 |
| 🎓 수능영어 | 수능 영어 문항 | 수능 대비, 평가원 스타일 |

### 프롬프트 강화 과정

#### 1단계: 원본 프롬프트 입력
```
"환자의 질문에 정확한 의학 정보를 제공하세요."
```

#### 2단계: 도메인 암묵지 주입
```python
# 시스템이 자동으로 추가하는 요소들:
1. 도메인 전문가 역할 부여
2. 핵심 원칙 3개 추가
3. 제약조건 3개 추가
```

#### 3단계: 강화된 프롬프트 출력
```
당신은 의료/헬스케어 분야의 전문가입니다.

핵심 원칙:
- 환자 안전이 최우선입니다
- 정확한 의학적 정보만 제공합니다
- 전문의 상담을 권장합니다

준수사항:
- 자가진단 유도 금지
- 처방 권고 금지
- 확인되지 않은 정보 금지

환자의 질문에 정확한 의학 정보를 제공하세요.
```

### 핵심 컴포넌트 설명

#### DomainKnowledge (도메인 암묵지)
전문가들이 암묵적으로 알고 있지만 명시하지 않는 지식을 구조화

| 요소 | 설명 | 예시 |
|------|------|------|
| principles | 핵심 원칙 | "환자 안전이 최우선" |
| constraints | 절대 지켜야 할 제약 | "처방 권고 금지" |
| quality_criteria | 품질 평가 기준 | 정확성 30%, 안전성 40% |
| thinking_styles | 전문가 사고방식 | "증상→원인→치료 순 분석" |
| expert_personas | 전문가 페르소나 | "20년차 내과 전문의" |

#### DomainAwarePromptOptimizer
프롬프트 강화 및 평가를 담당하는 핵심 엔진

```python
# 주요 메서드
optimizer.enhance_base_instruction(prompt)  # 프롬프트 강화
optimizer.evaluate_response(response)       # 응답 평가
optimizer.generate_domain_critique(...)     # 비평 생성
optimizer.get_domain_expert_prompt()        # 전문가 프롬프트
```

## 기능별 사용법

### 1. 도메인 정보 탭

**목적**: 선택한 도메인의 암묵지 확인

**사용 방법**:
1. 사이드바에서 도메인 선택
2. "도메인 정보" 탭 클릭
3. 4개 하위 탭에서 상세 정보 확인:
   - 🎯 핵심 원칙: 도메인의 기본 원칙들
   - 🚫 제약조건: 절대 위반하면 안 되는 규칙
   - 📊 품질 기준: 응답 평가 기준과 가중치
   - 🧠 사고방식: 전문가의 접근 방식

### 2. 프롬프트 최적화 탭

**목적**: 기본 프롬프트를 도메인 전문 프롬프트로 강화

**일반 도메인 (의료/법률/금융)**:
1. "프롬프트 최적화" 탭 선택
2. 작업 설명 입력 (선택)
3. 기본 지시문 입력
4. 답변 형식 지정 (선택)
5. 강화된 프롬프트 확인
6. 복사 또는 라이브러리 저장

**영어문항생성 도메인**:
1. 문항 유형 선택 (문법/어휘/독해/대화문/듣기)
2. 난이도/학년 선택
3. 세부 설정 (문항 수, 목표 문법, 주제 등)
4. 교육과정 성취기준 연계 (선택)
5. "템플릿 기반 프롬프트 생성" 클릭

**수능영어 도메인**:
1. 듣기(1-17번) 또는 독해(18-45번) 탭 선택
2. 문항 번호 선택
3. 문항 정보 확인 (배점, 난이도, 핵심 능력)
4. 세부 설정 (주제, 해설 포함 여부)
5. "수능 문항 프롬프트 생성" 클릭

### 3. 응답 평가 탭

**목적**: AI 응답의 도메인 적합성 평가

**사용 방법**:
1. "응답 평가" 탭 선택
2. 평가할 AI 응답 입력
3. 테스트 케이스 선택 (선택)
4. 평가 결과 확인:
   - 종합 점수
   - 개별 메트릭 점수
   - 결정론적 검증 결과
5. 케이스 검증 결과 확인 (테스트 케이스 선택 시)

### 4. 커스텀 도메인 탭

**목적**: 새로운 도메인 설정 생성

**사용 방법**:
1. "커스텀 도메인" 탭 선택
2. 도메인 이름/타입 입력
3. 핵심 원칙 입력 (줄바꿈으로 구분)
4. 제약조건 입력 (줄바꿈으로 구분)
5. "도메인 설정 생성" 클릭

## 도메인별 가이드

### 🏥 의료 도메인

**적합한 사용 사례**:
- 건강 정보 제공 챗봇
- 의학 교육 자료 생성
- 환자 상담 시나리오

**핵심 원칙**:
1. 환자 안전 최우선
2. 전문의 상담 권장
3. 정확한 정보만 제공

**주의사항**:
- 자가진단 유도 금지
- 처방 권고 금지
- 응급 상황 안내 포함

### ⚖️ 법률 도메인

**적합한 사용 사례**:
- 법률 정보 제공
- 계약서 검토 보조
- 법률 용어 설명

**핵심 원칙**:
1. 법적 책임 고지
2. 변호사 상담 권장
3. 최신 법령 확인 권고

### 💰 금융 도메인

**적합한 사용 사례**:
- 투자 정보 제공
- 재무 분석 보조
- 금융 교육 자료

**핵심 원칙**:
1. 투자 위험 고지
2. 개인별 상황 고려 권고
3. 공인된 정보 기반

### 📝 영어문항생성 도메인

**적합한 사용 사례**:
- 학교 영어 시험 출제
- 모의고사 문항 제작
- 수준별 학습 자료

**문항 유형**:
| 유형 | 설명 |
|------|------|
| 문법 - 시제 | 동사 시제 관련 문항 |
| 문법 - 문장구조 | 관계사, 분사, 가정법 |
| 어휘 - 문맥상 의미 | 단어 의미 추론 |
| 독해 - 주제/요지 | 글의 핵심 파악 |
| 독해 - 빈칸 추론 | 문맥 기반 추론 |
| 독해 - 순서 배열 | 글의 논리적 순서 |
| 대화문 | 응답 완성 |
| 듣기 | 듣기 이해 문항 |

### 🎓 수능영어 도메인

**적합한 사용 사례**:
- 수능 대비 문항 제작
- 평가원 스타일 모의고사
- 문항번호별 맞춤 연습

**문항 구조**:
```
┌─────────────────────────────────────┐
│ 듣기 영역 (1-17번)                   │
├─────────────────────────────────────┤
│ 1번: 목적 파악                       │
│ 2번: 의견 파악                       │
│ 3번: 관계 파악                       │
│ ...                                 │
│ 16-17번: 세트 문항                   │
├─────────────────────────────────────┤
│ 독해 영역 (18-45번)                  │
├─────────────────────────────────────┤
│ 기본 독해: 18-27번                   │
│ 어법/어휘: 28-29번 (3점)             │
│ 빈칸 추론: 21, 30-34번 (고난도 포함) │
│ 글의 구조: 35-40번                   │
│ 장문: 41-45번                        │
└─────────────────────────────────────┘
```

**고난도 문항 (3점)**:
- 21번: 함축 의미 추론
- 28번: 어법
- 29번: 어휘
- 32-34번: 빈칸 추론

## 고급 기능

### 프롬프트 라이브러리

**저장하기**:
1. 프롬프트 강화 후 "💾 라이브러리에 저장" 클릭
2. 프롬프트 이름 입력
3. 저장 완료

**불러오기**:
1. "📚 라이브러리 보기" 클릭
2. 저장된 프롬프트 목록에서 선택
3. 복사 또는 재사용

### 차이점 분석

강화된 프롬프트와 원본의 차이를 자동 분석:
- ✅ 추가된 도메인 원칙 수
- 🚫 추가된 제약조건 수
- 👤 전문가 관점 추가 여부
- 📊 품질 기준 반영 여부
- 📝 텍스트 길이 증가량

### 결정론적 검증

프롬프트에 설정된 Validator를 통한 자동 검증:
- **KeywordValidator**: 필수 키워드 포함 확인
- **RegexValidator**: 정규식 패턴 매칭
- **JsonSchemaValidator**: JSON 스키마 준수 확인

## FAQ

### Q: 어떤 도메인을 선택해야 하나요?
**A**: 작업 목적에 맞는 도메인을 선택하세요:
- 건강/의료 관련 → 의료 도메인
- 법률 자문 관련 → 법률 도메인
- 투자/재무 관련 → 금융 도메인
- 영어 시험 출제 → 영어문항생성
- 수능 영어 대비 → 수능영어

### Q: 강화된 프롬프트가 너무 길어요
**A**: 강화된 프롬프트는 도메인 지식이 추가되어 길어집니다. 이는 의도된 것이며, AI가 더 정확하고 안전한 응답을 생성하는 데 도움이 됩니다.

### Q: 커스텀 도메인을 영구 저장할 수 있나요?
**A**: 현재 버전에서는 세션 내에서만 유지됩니다. 영구 저장이 필요하면 JSON 설정을 복사하여 별도 보관하세요.

### Q: 수능영어 문항이 실제 수능과 다를 수 있나요?
**A**: 네, 이 도구는 수능 스타일의 문항 생성을 돕지만, 실제 평가원 출제 기준과 완전히 동일하지 않을 수 있습니다. 교사나 전문가의 검토를 권장합니다.

### Q: API 키가 필요한가요?
**A**: 기본 프롬프트 강화 기능은 API 키 없이 사용 가능합니다. LLM 기반 평가나 비평 생성 기능을 사용하려면 OpenAI API 키가 필요합니다.
