# 호텔리어 고객 응대 영어 훈련 앱 PRD (Refined)

- 작성일: 2026-04-09
- 버전: v1.0
- 키워드: #호텔영어 #응대훈련 #시나리오

## 1) 제품 목표
호텔 프론트/컨시어지/객실 서비스 담당자가 실제 고객 질문에 대해 **자연스럽고 정확한 영어 응대**를 빠르게 연습하도록 지원한다.

## 2) 타깃 사용자
- 신규 호텔리어(입사 1년 미만)
- 비영어권 호텔 스태프
- 서비스 품질 코칭 담당 매니저

## 3) 핵심 문제
- 상황별 응대 문장을 외워도 실제 대화에서 즉시 꺼내기 어렵다.
- 발화 정확도(표현/정중함/완결성) 피드백을 즉시 받기 어렵다.
- 개인별 취약 주제를 추적하기 어렵다.

## 4) 핵심 가치 제안
- **시나리오 기반 반복 훈련**으로 실전 대처 능력 강화
- **즉각 피드백**으로 표현 정확도와 자신감 동시 향상
- **진행 추적**으로 주제별 취약점 확인 및 개선

## 5) 기능 요구사항 (MVP)

### 5.1 시나리오 학습
- 총 20개 기본 시나리오 제공
- 주제: 체크인, 객실 요청, 시설 안내, 교통/관광, 불만 처리
- 각 시나리오 구성:
  - 고객 질문(영문)
  - 추천 응답(모범 답안)
  - 변형 표현(대체 문장)

### 5.2 응답 방식
- **객관식 모드**: 4지선다 중 적절한 응답 선택
- **스피킹/자유응답 모드**:
  - 음성 입력(가능 환경) 또는 텍스트 입력
  - 모범 답안과 비교하여 핵심 표현 포함 여부 평가

### 5.3 즉각 피드백
- 정답/오답 여부
- 왜 좋은 표현인지(정중함, 정보 완결성, 행동 제시)
- 개선 문장 제안

### 5.4 진행 추적
- 전체 완료율
- 모듈별 정확도
- 자주 틀리는 문항 목록

## 6) 비기능 요구사항
- 3클릭 이내 학습 시작 가능한 직관적 UI
- 모바일/데스크톱에서 읽기 쉬운 레이아웃
- 학습 상태(session) 즉시 반영

## 7) 성공 지표 (KPI)
- 시나리오 정답률 평균 20%p 향상(4주)
- 재방문율(주 2회 이상) 50%+
- 사후 설문: “영어 응대 자신감 상승” 응답 4.2/5 이상

## 8) 향후 확장
- 음성 인식/발음 점수(ASR/TTS 연동)
- 난이도 자동 조절(초급/중급/고급)
- 실제 호텔 SOP 맞춤 시나리오 업로드

## 9) 초기 콘텐츠(20개) 운영 원칙
- 모든 답변은 정중 표현 포함(예: Certainly, I’d be happy to...)
- 행동/다음 단계 제시(예: I’ll arrange..., Let me check...)
- 시간/위치/대안 정보 제공 우선
